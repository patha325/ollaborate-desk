# Strands Harness evaluation result — 2026-09-25

## Decision

Keep **Ollaborate** as Ollaborate Desk's default runtime. Do not enable Strands Harness in the product yet. Its session resume is useful, while the deterministic run cannot establish an answer-quality or task-completion advantage. Prototype it behind an optional adapter only after a live Ollama comparison on the target PC and a separate action-policy test.

## Run and observations

- Python 3.12 isolated environments; Ollaborate 0.1.0, Strands Harness 0.1.2, Strands Agents 1.57.0. Both called the same in-process deterministic Ollama fixture with `qwen3:8b` as model identifier.
- 20 tasks: 10 supported facts, 5 missing evidence, 5 file excerpts containing hostile instructions. The same SQLite FTS5 excerpts reached each runtime. Both used a planner and writer, totaling **40 model calls each**.
- Strands had **zero registered tools** and the recorded Ollama requests from both runtimes contained **zero tool specifications**. The configured provider used a loopback URL. The fixture cannot establish that an installed process lacks other network paths.
- A new Strands agent with the same local session id received the earlier user turn in its model request. Desk's existing task history stores drafts but does not resume an agent conversation in the same way.
- Median fixture orchestration time per task: Ollaborate below the timer's 1 ms reporting resolution; Strands approximately **15 ms**. Model inference and GPU work were replaced by a fixed response, so these timings are only harness overhead in this environment.
- Fresh virtual environments: baseline site-packages **51 MB / 27 distributions**; with Strands **147 MB / 71 distributions**. This is installation footprint, not inference VRAM.
- Existing tests in the Strands environment: **7 passed, 1 skipped** (optional LibreIndex). Baseline environment: **4 passed, 2 skipped** (LibreIndex and Strands optional tests).

## Limits and next gate

There was no Ollama server or NVIDIA GPU available in this workspace; `127.0.0.1:11434` refused a connection. No live-model quality, prompt-injection resilience, RTX 3070 speed, context-window behavior, or offline network-denial result is claimed. The hostile excerpts in the fixture measure evidence delivery and tool exposure, not whether a real model follows malicious instructions.

Run `evaluation/compare.py --live` on the target PC and inspect its four outputs, GPU placement, and memory use. Before enabling Strands actions, test path escape, unapproved writes, outbound requests, and rollback under an OS-enforced network policy. Reconsider the optional adapter if the live run shows a concrete multi-step or session-resume benefit without worse grounding or offline guarantees.
